# Foundry Architecture Documentation

This directory contains detailed architecture documentation for the Foundry system.

## Overview

The Foundry architecture is designed to be modular, extensible, and maintainable. The high-level architecture is described in the main `architecture.md` file in the parent directory.

This directory will be expanded with detailed documentation on specific aspects of the architecture as the system evolves.

## Contents

- [Architecture Overview](architecture.md) - High-level architectural design of Foundry
- [Adapters](adapters.md) - Detailed specification for the adapter system, including core methods and data transformation
- [Agents](agents.md) - Comprehensive documentation on the agent system, including agent types and implementation details
- [Consumers](consumers.md) - Specification for the consumer interfaces that provide access to Foundry functionality
- [Core Library](core.md) - Details of the central component that contains business logic and orchestrates the system
- [Artifacts](artifacts.md) - Description of the various artifacts that Foundry generates and manages
- [Execution Framework](execution.md) - Task definition, context management, execution pipeline, and review processes
- [Memory Module](memory.md) - Future extension to adapters for vectorization and relationship graphing
- **Agent Lifecycle**: (Coming soon) Documentation on the agent lifecycle and review processes
- **Tool Extension System**: (Coming soon) How to create and manage tools that extend Foundry
