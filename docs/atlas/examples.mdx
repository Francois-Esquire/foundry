## Foundry

This is Atlas reading its own repository. Each documentation build scans the
current checkout and includes the saved dataset with the same viewer shipped
in the CLI.

Drag or zoom to explore the map above. Open the full-screen map for more room.

The viewer loads static files. It does not scan your machine or need a running
Atlas server. The manifest records the scan time, coverage, and any skipped
packages. Historical checkpoints are not included in this example.

## Build the example locally

From the Foundry repository root:

```sh
bun install --frozen-lockfile
bun run docs:build
```

The build generates the example in `docs/public/atlas/examples/foundry/` and
copies it into `docs/dist/atlas/examples/foundry/`. Generated files are ignored
by Git. `bun run docs:dev` refreshes the example before starting the docs server.
