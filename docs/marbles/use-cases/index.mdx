## Available patterns

These patterns include modules that load and run with the current
library. Model operations require an installed, authenticated Claude Code or
Codex CLI; `--dry-run` echoes them.

<CardGroup cols={2}>
  <Card title="Repository Caretaker" href="/marbles/use-cases/repository-caretaker">
    Observe instruction files, then investigate what changed.
  </Card>
  <Card title="Persistent Reviewer" href="/marbles/use-cases/persistent-reviewer">
    Revisit a repository with earlier findings in conversation history.
  </Card>
  <Card title="Implement–Review Loop" href="/marbles/use-cases/implement-review">
    Give implementation and review separate turns and hand the branch between them.
  </Card>
  <Card title="Release Watcher" href="/marbles/use-cases/release-watcher">
    Observe an external release feed and assess its relevance.
  </Card>
</CardGroup>

“Release Watcher” is a pattern name. The API object observing the feed is a monitor.
