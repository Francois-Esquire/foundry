## Available patterns

These patterns use current APIs and include runnable configurations or built-in
commands. Model operations require an authenticated harness.

<CardGroup cols={2}>
  <Card title="Repository Caretaker" href="/quirks/use-cases/repository-caretaker">
    Observe instruction files and Git history, then investigate changes.
  </Card>
  <Card title="Persistent Reviewer" href="/quirks/use-cases/persistent-reviewer">
    Revisit a repository with earlier findings in conversation history.
  </Card>
  <Card title="Implement–Review Loop" href="/quirks/use-cases/implement-review">
    Give implementation and review separate turns and feed findings into another attempt.
  </Card>
  <Card title="Release Watcher" href="/quirks/use-cases/release-watcher">
    Observe an external release feed and assess its relevance.
  </Card>
</CardGroup>

“Release Watcher” is a pattern name. The API object observing the feed is a monitor.
