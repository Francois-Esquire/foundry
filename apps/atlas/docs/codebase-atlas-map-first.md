# Map-first belonging

Atlas exploration starts on the terrain. The permanent index no longer owns the
journey. Preserve the coastline, file coordinates, paper, ocean, and canonical
evidence identifiers.

## Interaction

- Enter an island to see its responsibility regions immediately.
- Hover a region to strengthen its pigment and mark its exact member files.
- Click to pin it. A short inspector names the group and offers its files and
  architectural evidence. Clicking water clears the selection.
- Search and a compact breadcrumb provide keyboard navigation. The full index
  and detailed evidence are optional, never prerequisites to seeing belonging.
- Zoom reveals files and then composition. Only one grouping layer dominates.
- Unresolved files have broken boundaries. They are not assigned to a candidate.
- Tracing paper preserves the current region beneath proposed changes.

## Region geometry

Compute compact influence footprints from displayed member coordinates. Take
their union, contour it, and clip the drawing to existing land, including holes.
An isolated file contributes the same minimum footprint as a dense cluster.
Disconnected patches keep one color and identity. Neither the coastline nor file
placement consumes this field. Enclosed nonmembers remain nonmembers.

## Verification

Pure tests cover isolated and disconnected members, deterministic ordering,
holes, exact membership, and unchanged source geometry. Browser checks cover
automatic arrival, hover, pin, file selection, advanced evidence, search, escape,
water deselection, and desktop/mobile layout. Retain retry and stale-survey
handling. No semantic-tooling changes.

## Delivered

Belonging loads on island arrival. Regions, search, breadcrumbs, and the compact
inspector replace the permanent index. File selection loads composition without
opening evidence. Architectural matches use the same footprint treatment; tracing
paper retains the current belonging pigment beneath the proposed marks.

Footprints intentionally overlap where members are interleaved. Pinning isolates
one group without claiming the enclosed nonmembers. The default drawing has not
been reorganized to manufacture clean districts.

Verified with 90 package tests, typecheck, scoped lint, formatting, and a static
build. Headless Chromium covers desktop/mobile arrival, region hover and pin,
member selection, automatic composition, optional evidence, retry, keyboard search,
empty results, layer switching, import tracing, water deselection, and a real
split alternative at midpoint and full tracing. The independent visual review
returned `ship`. Existing build warnings concern the large client chunk, missing
docs 404 entry, and unset sitemap site.
