# Viewer typefaces

Bundled locally; no font service is contacted by the viewer.

- Abril Fatface Regular: TypeTogether, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/abrilfatface). The unmodified TrueType file is accompanied by `AbrilFatface-OFL.txt`.
- Inter Regular: the same unmodified WOFF2 used by `apps/foundry.sh`, from the [Inter project](https://github.com/rsms/inter), accompanied by `Inter-OFL.txt`.

The viewer registers these as AtlasDisplay and AtlasBody. The old record's
Calibre asset and design package were absent from this standalone app.
