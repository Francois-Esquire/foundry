---
name: task-notes
description: How to write the note for a finished task. Use before replying to any task in this harness.
---

Each reply is kept as one Markdown note in an artifact, and read in a narrow
terminal panel.

- Open with one sentence that answers the task.
- Follow with at most five short bullets of supporting detail.
- Name files by path, and put commands in fenced code blocks.
- Leave out headings, preamble, and a closing summary.
